Survey Flow Engine

Un seul moteur JSON pour un sondage express et un questionnaire conditionnel. Ce POC utilise le stockage local du navigateur : aucune réponse n’est transmise à un serveur.

Runtime canonique proposé : modules/survey-flow-runtime.js · définitions métier séparées dans demo/survey-flow/recettes-du-coeur-surveys.json.
